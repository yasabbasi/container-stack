# container-stack

Runs [task-agent](https://github.com/yasabbasi/task-agent),
[data-pipeline](https://github.com/yasabbasi/data-pipeline) and
[mcp-server](https://github.com/yasabbasi/mcp-server) from containers, on any machine.

Nothing runs yet. The plan is in [docs/plan.md](docs/plan.md); the owner approved it on
2026-11-24 and the work is under way.

## Development

- `make check` runs the linters and the tests. CI runs the same command.
- `make format` fixes style and formatting.
